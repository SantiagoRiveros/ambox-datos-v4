¿Qué es el EDA?

El Análisis Exploratorio de Datos (Exploratory Data Analysis - EDA) es el proceso de examinar un conjunto de datos para comprender su estructura, 
calidad y comportamiento antes de realizar análisis más complejos o construir modelos predictivos.

El objetivo del EDA no es responder una única pregunta, sino descubrir información que inicialmente no conocemos.

Durante un EDA buscamos:

-Conocer el dataset.
-Detectar errores.
-Identificar datos faltantes.
-Encontrar relaciones entre variables.
-Detectar valores atípicos.
-Descubrir patrones.
-Formular hipótesis.

¿Por qué es importante?

Un analista rara vez recibe un dataset perfecto. Antes de responder preguntas de negocio debe verificar que los datos sean confiables.

Paso 4 - Detectar valores extremos

Boxplot
sns.boxplot(
    data=df,
    y="price"
)

¿Qué es un outlier?

Es un dato que se aleja considerablemente del resto.

Ejemplos:

-un producto de $50.000 cuando la mayoría cuesta $100;
-una edad de 150 años;
-un envío con costo negativo.

¿Siempre debe eliminarse?

No.

Puede representar:

-un error;
-un caso excepcional;
-un dato completamente válido.

Detectar anomalías con IQR
Una forma clásica de detectar posibles outliers es utilizar el rango intercuartílico (IQR).

Q1 = df["price"].quantile(0.25)
Q3 = df["price"].quantile(0.75)

IQR = Q3 - Q1

limite_inferior = Q1 - 1.5 * IQR
limite_superior = Q3 + 1.5 * IQR

outliers = df[
    (df["price"] < limite_inferior) |
    (df["price"] > limite_superior)
]

print(outliers)

print(len(outliers))
